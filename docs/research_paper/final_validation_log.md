## Method definitions used in this snapshot

- **A:** rank by supplied popularity score only.
- **B:** score `0.50 × scenic + 0.30 × activity-specific weather + 0.20 × popularity`. Weather is built from piecewise temperature and rainfall fit functions; trekking uses a 0.5/0.5 temperature/rain fit, waterfalls 0.4/0.6.
- **C:** Method B plus only evidence-backed, current, destination/month/activity/scope-applicable restrictions. A qualifying full-destination closure is quarantined from the actionable ranking; qualifying partial restrictions apply their configured multiplier. The values in the supplied dataset do not currently exercise this path.

Weights and multipliers are design parameters, not empirically optimized values.

## Baseline results (provisional inputs)

Overall 36-scenario macro-average NDCG@K: A=0.6143, B=0.9776, C=0.9776. Category-specific 24-scenario NDCG@3: A=0.6483, B=0.9789, C=0.9789. Overall Precision@K: A=0.6852, B=0.8852, C=0.8852. K varies by scenario pool, so overall is not a fixed-K statistic.

Full-closure conflict is N/A for all methods and all 36 scenarios: 16 scenario-method results have no qualifying closure record, and 20 have supplied closure claims but insufficient evidence. The 0 evidence-backed disruption count means Method C ties Method B; it is not a measured safety improvement. Relevance metrics are estimable for all current scenarios, but their labels are provisional and potentially aligned with the same seasonal features used by the rankers.

## Outstanding validation gates

The data audit and annotation files are review instruments, not proof of validation. All 108 labels still need blinded independent assessments, source evidence, disagreement review, and adjudication. All 11 disruption records remain unverified; the current source search identified some general seasonal information and narrower/historical notices, but no evidence set that validates the supplied claims as applicable current closures. Do not replace this baseline with “final” claims until the rubric is approved, reviews are complete, source evidence is recorded, and the frozen benchmark is rerun.
